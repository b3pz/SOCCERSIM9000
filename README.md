# NOI, FINO A QUI

Piccola esperienza narrativa privata per l'anniversario, pensata soprattutto per smartphone. La storia parte dal 7 settembre 2020, il giorno in cui vi siete conosciuti, e arriva al 7 settembre 2026.

## Pubblicarla su GitHub Pages

1. Crea un nuovo repository su GitHub.
2. Carica **tutto il contenuto di questa cartella nella root del repository**:
   - `index.html`
   - `styles.css`
   - `script.js`
   - `favicon.svg`
   - cartella `assets/`
3. Apri **Settings → Pages**.
4. In **Build and deployment**, scegli **Deploy from a branch**.
5. Seleziona `main` e `/ (root)`, poi salva.
6. Dopo pochi minuti GitHub mostrerà il link pubblico.

## Personalizzazioni rapide

- Il testo è tutto dentro `index.html`.
- Le note romantiche si trovano negli attributi `data-note`.
- Le immagini sono in `assets/photos/`.
- Non servono librerie, npm o build.

## Privacy

Se il repository è pubblico, anche le foto saranno pubblicamente accessibili tramite il link.
Per una condivisione più riservata, valuta un hosting/accesso privato o rimuovi il progetto dopo l'anniversario.


## Novità di questa versione
